## Description:

Nesse mini game, o algoritmo sorteia um número pseudoaleatório em um período predefinido e o jogador pode realizar tentativas a fim de descobrir este número secreto.

> O código contabiliza e informa a quantidade de tentativas que o jogador realizou, possuí uma pequena interatividade de imagem com HTML e permite opção de acessibilidade com leitura da página por voz.
